# 🎮 CodeAlpha Hangman Game

A simple console-based Hangman game developed using Python as part of the CodeAlpha Python Programming Internship.

## 📌 Project Description

This project is a beginner-friendly Hangman game where the computer randomly selects a word from a predefined list. The player must guess the hidden word one letter at a time.

The player gets **6 lives** for incorrect guesses. Correctly guessed letters are revealed, while incorrect guesses reduce the remaining lives.

## ✨ Features

* 🎲 Random word selection
* 🔤 Letter-by-letter guessing
* ❤️ 6 lives for incorrect guesses
* 🔒 Hidden word display
* ⚠️ Input validation
* 🔄 Duplicate guess protection
* 🎉 Win and game-over conditions
* 💻 Console-based interface

## 🛠️ Technologies Used

* Python
* `random` module
* Lists
* Strings
* `while` loop
* `if-else` statements
* `for` loop
* User input

## 🎯 Game Rules

1. The game randomly selects one word from five predefined words.
2. The hidden word is displayed using underscores.
3. Enter one letter at a time.
4. A correct letter is revealed in its position.
5. An incorrect guess reduces one life.
6. The player has a maximum of 6 incorrect guesses.
7. The player wins when all letters are revealed.
8. Repeated letters and invalid inputs are handled by the program.

## ▶️ How to Run

Make sure Python is installed on your computer.

Open the project folder in VS Code and run:

```bash
python hangman.py
```
